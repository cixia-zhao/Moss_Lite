## 1. 项目定位

MOSS-Lite 是一个本地运行的**赛博朋克风自律数据控制舱**。通过局域网在手机和电脑上共享访问，用一个高科技感的虚拟智脑核心进行交互，能根据用户所处的生命周期（备考、竞赛、休假等）自适应调整分析逻辑和提醒策略。

### 核心特性

| 特性 | 描述 | 实现状态 |
|------|------|---------|
| 太空舱赛博视觉 | 深色控制台，全息核心动画，霓虹色系 | ✅ 已实现 |
| 自适应模式系统 | 内置模式 + 用户自定义生命模式 | ✅ 已实现 |
| 专注计时器 | 计时/手动补登，自定义预设和标签 | ✅ 已实现 |
| 收支记账 | 手动记录 + 微信/支付宝 CSV 导入 | ✅ 已实现 |
| 洛谷数据同步 | 自动爬取 Rating、题目统计 | ✅ 已实现 |
| 学习热力图 | 赛博色阶热力图 + 未来事件倒计时 | ✅ 已实现 |
| 带记忆的智脑 | 长期记忆提取 + 陪伴式 AI 闲聊 | ✅ 已实现 |
| 主动推送提醒 | 定时触发，推送到手机 | ❌ 未实现 |
| 沉浸专注模式 | 计时时降低周围亮度，聚焦核心 | ❌ 未实现 |
| 每日综合评级弹窗 | 每日 Rating 详情和 AI 点评 | 🟡 部分实现（Rating 有，弹窗无）|

## 2. 系统架构

```
用户设备（电脑/手机）
  │ 局域网访问
  ▼
FastAPI 后端服务
  ├─→ 托管 React 前端（静态资源）
  ├─→ SQLite 数据库（本地存储）
  ├─→ 洛谷爬虫服务
  ├─→ 账单 CSV 解析服务
  ├─→ DeepSeek AI 智脑引擎（API 调用）
  └─→ [未来] 推送调度器 → Bark / PushDeer
```

**技术栈**：
- 前端：React (Vite) + 原生 CSS（赛博朋克主题）
- 后端：Python (FastAPI) + SQLAlchemy + SQLite
- 部署：`run.py` 一键启动，局域网 IP 访问

## 3. 设计理念

### 视觉风格

- **深空背景** + **霓虹高对比度**（Cyan `#66FCF1` / Pink / Purple）
- 全息核心动画：Canvas 渲染旋转几何体，状态驱动变化
  - 日常：平缓青色波形
  - 专注中：荧光蓝加速旋转
  - 休假：幽蓝慢呼吸
  - 警告：红色脉冲闪烁
- 热力图色阶：无活动 `#1A1C23` → 满载活跃 `#66FCF1`

### 交互理念

- **一切数据一目了然**：统计面板、热力图、账本在同一页面展示
- **AI 不只是工具，是伙伴**：记忆系统让 AI 记住用户的目标和心事，主动关怀
- **模式驱动自适应**：不同生活阶段切换模式，AI 行为和分析逻辑自动调整

## 4. 未实现功能规划

### 推送提醒系统（优先级：中）

**设计思路**：
- 后端定时任务（`apscheduler`）
- 用户自定义触发规则：时间点 + 条件（如"今日学习 < 60 分钟"）
- 推送通道：Bark（iOS）/ PushDeer（微信）/ Server 酱
- 推送文案：固定模板 或 AI 根据当日数据动态生成

**所需改动**：
- 新增 `reminder_rules` 数据库表
- 新增 `api/reminders.py` 路由
- `main.py` 中 `check_and_send_reminders()` 已有占位函数
- Settings 页面增加提醒规则配置 UI

### 沉浸专注模式（优先级：低）

**设计思路**：
- 计时启动时触发全局 CSS 遮罩，降低非核心区域亮度
- 仅高亮全息核心 + 计时器
- 通知音效或振动提醒

### 每日综合报告弹窗（优先级：低）

**设计思路**：
- 每天首次打开时弹出昨日报告
- 包含：学习时长、做题数、收支、Rating、AI 点评
- 需要 `ai_diary_review` 字段的实际调用
